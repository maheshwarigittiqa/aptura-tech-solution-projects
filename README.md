# Mobile Banking Application

## Project Overview

This project was created as part of my UI/UX internship at Aptura Tech Solutions.

The goal was to design a simple, secure, and easy-to-use mobile banking application that allows users to manage their accounts and transfer money easily.

## Features

- Splash screen
- Login screen
- OTP verification
- Account dashboard
- Balance card
- Quick actions
- Recent transactions
- Money transfer
- Transfer confirmation
- Transaction success screen
- Profile section
- Bottom navigation

## UX Process

The project includes:

- User Persona
- Low-Fidelity Wireframes
- User Flow
- High-Fidelity UI Design
- Design System
- Components and UI States

## User Flow

Open App → Login → OTP Verification → Dashboard → Transfer Money → Review Details → Confirm Transaction → Transaction Successful

## Design System

The design system includes:

- Primary Blue: #2F6BFF
- Secondary Green: #16C784
- Background: #F8FAFC
- Surface: #FFFFFF
- Primary Text: #111827
- Secondary Text: #6B7280
- Border: #E5E7EB
- Error: #EF4444
- Warning: #F59E0B

Typography uses Poppins and Inter.
