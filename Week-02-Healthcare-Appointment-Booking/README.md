# Healthcare Appointment Booking Application

## Project Overview

This project was created as part of my UI/UX internship at Aptura Tech Solutions.

The Healthcare Appointment Booking Application was designed to make the appointment booking process simple, fast, and user-friendly.

Users can search for doctors, view doctor profiles, check availability, select a date and time, and confirm their appointment easily.

## Objective

The objective of this project was to design a modern healthcare mobile application that makes booking a doctor's appointment easier and more convenient.

The design process focused on usability, accessibility, consistency, and a complete UX workflow from research to high-fidelity prototyping.

## UX Design Process

The project followed these UX design stages:

- User Research
- User Persona
- User Journey Map
- Information Architecture
- Low-Fidelity Wireframes
- High-Fidelity UI Design
- Interactive Prototype
- Design System

## User Research

The research identified the following user needs:

- Users prefer a quick and simple appointment booking process.
- Doctor availability should be easy to view before booking.
- Appointment reminders help users avoid missing appointments.
- Searching doctors by specialization makes the process faster.
- Ratings and reviews help users choose trusted doctors.

## Accessibility Considerations

The design considers accessibility through:

- High color contrast
- Large touch targets
- Clear and readable typography
- Consistent navigation
- Simple labels and icons
- Clear visual hierarchy
- Straightforward booking process

These improvements make the application easier to use for people of different ages, technical skill levels, and accessibility needs.

## Usability Evaluation

The design was reviewed using Nielsen's usability principles.

Five usability challenges were identified:

1. **Small Touch Targets**  
   Button and interactive element sizes were improved to make tapping easier on mobile devices.

2. **Low Text Contrast**  
   Text contrast was improved for better readability in different lighting conditions.

3. **Complex Booking Process**  
   Unnecessary steps were reduced and the booking flow was organized more logically.

4. **Limited System Feedback**  
   Confirmation messages and a booking success screen were added so users know when an appointment has been successfully booked.

5. **Difficulty Checking Doctor Availability**  
   Doctor availability, ratings, and consultation details were displayed more clearly to help users make better decisions.

## Design for Different Users

- Consistent colors and typography

- A simple appointment booking process
